# lochan-eda documentation site

A scikit-learn-inspired documentation system for the `lochan-eda` Python package.

The documentation is designed to live inside the portfolio under:

`/work/lochan-eda/docs`

## Design

This version intentionally avoids a marketing-style landing page.

It uses:

- dense technical navigation
- User Guide + API Reference separation
- class-oriented API pages
- method index tables
- signatures and examples
- cross-links between concepts and APIs
- compact typography
- restrained color
- long-form reference pages
- responsive navigation

No additional npm dependency is required.
